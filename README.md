# fb-library (v2.0.0)

A modern C++ template library featuring high-performance utilities and compile-time concepts.

## Features
- Traits with aliases such as `fb::remove_cvref_t`, `fb::is_same_v`, and `fb::add_pointer_t`.
- Concepts such as `fb::integral` and `fb::character` made using the traits.
- Simple mathematical functions
- Testing suite with a dedicated tests/ directory.

## Running tests
This repository includes a testing suite in the tests/ directory. To compile, execute your local build system or compiler commands from the root directory.
